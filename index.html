    Where your keys live
    
        
    
          
          
        
    
        
    Keys stay in this tab’s memory and are forgotten when you refresh or close it. Nothing is written to disk.
    
        
    
          
    
          
    
        
    
        
    
          
    
          
    
        
    
        
    Keys are saved on this device, encrypted with your passphrase (AES-GCM, PBKDF2). 
    
        
    Browser keys can be exposed. Requests go straight from this page to each provider, so a malicious browser extension or anyone using this browser profile could read them. Use free-tier keys with no billing attached, never paste a key tied to a card, and revoke any key you think leaked. This site has no server and never receives your keys or transcripts.

    Publish on GitHub Pages
    
    
      
      
    1. Create a new repository on GitHub (public, or private on a plan that allows Pages).
      2. 
      
    2. Upload this index.html to the repository root and commit.
      3. 
      
    3. Open Settings → Pages, choose Deploy from a branch, branch main, folder / (root), and save.
      4. 
      
    4. Wait a minute, then open https://<your-username>.github.io/<repo-name>/.
      5. 
      
    5. Go to AI settings, paste a free key, tick Allow transcripts and the free-plan confirmation, then press Test connection.
      6. 
      
    6. Back on Analyze, drop a transcript and press Analyze workshop.
      7. 
    
    
    
    The file also works when opened directly from your computer, but some providers and Ollama behave better from an https:// address.
    

    
    Free keys that work from a browser
    
    
      
      
    • Google Gemini — key from Google AI Studio. Use a project with no billing; the free tier covers the Flash and Flash-Lite models. Best first choice: 1M-token context.
      • 
      
    • Groq — free plan, very fast, but small per-minute token caps. The app paces requests and splits transcripts automatically.
      • 
      
    • OpenRouter — only models ending in :free with a listed price of $0 are ever used. Daily request caps are low unless you have bought credits once.
      • 
      
    • Hugging Face — small monthly free credits. Off in Auto mode until you allow it.
      • 
      
    • Ollama — runs on your own computer, free and private. See setup below.
      • 
      
    • Mistral, Cohere, custom endpoints — browser access is not confirmed. Press Test; Auto mode only uses them after a successful test.

    How the analysis works
    
    
      
      
    1. The transcript is split into segments sized for the chosen model, never dropping text. Caption files are merged into timestamped paragraphs.
      2. 
      
    2. Each segment is read for evidence: intro moves, lessons, prompts, tools, marketing, selling and course details, each with a timestamp.
      3. 
      
    3. The seven report sections are written from that evidence only, then a structured fact sheet is saved for comparisons.
      4. 
      
    4. If a model fails or hits a limit, the next free model takes over and you are told. If every model fails, you get an error and the progress so far is saved so you can resume.
      5. 
    
    

    
    Ollama setup (local AI)
    
    
    Browsers block pages from talking to Ollama unless Ollama allows the page’s address. Quit Ollama, then start it with your site’s origin allowed:
    
    
    OLLAMA_ORIGINS="https://<your-username>.github.io" ollama serve
    
    
    On macOS app installs: launchctl setenv OLLAMA_ORIGINS "https://<your-username>.github.io" and restart Ollama. On Windows, add OLLAMA_ORIGINS as a user environment variable and restart Ollama. Chrome may ask to allow access to devices on your local network — allow it. Safari may block it entirely. Pull a capable model first, e.g. ollama pull qwen3:14b, and set a context size of 16K or more in the provider card.
    

    
    Honest limits
    
    
      
      
    • Free tiers change often. Limits shown in the app are defaults you can edit; the provider’s own dashboard is the truth.
      • 
      
    • The app cannot see whether a key has billing attached. That is why each provider asks you to confirm its free plan before Auto mode uses it.
      • 
      
    • Some providers refuse browser requests (CORS). The app reports this as “blocked by the browser” instead of pretending.
      • 
      
    • Scanned PDFs (images of text) cannot be read here — export the transcript as text instead.
      • 
      
    • The direct PDF download embeds a Unicode font (loaded once from the CDN), so ₹ and accented text stay real text. Devanagari, emoji and other scripts are drawn as images so nothing turns into “?”. Offline, it still works but draws every special character as an image.
      • 
      
    • Data lives in this browser only. Use Back up everything in the library to keep a copy or move to another device.
      • 
      
    • The music is original generative jazz piano, synthesized live in your browser — no recordings are used.
